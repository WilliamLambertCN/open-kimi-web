# 已完成侧栏宽度与 2.6.1-r7 发布 v1

## 背景

官方 Kimi Code 2.6.1 的侧栏标题默认只为当前日期保留空间，鼠标悬停时才为操作按钮增加渐隐。
Open Kimi Web 在已完成会话的官方 `.ui-tip` 内加入恢复和永久删除操作，同时在 `.ha` 追加会话菜单。
旧样式因此让标题始终按三组操作宽度提前渐隐，即使操作区处于隐藏状态，日期前也会留下大块空白。

目标是让已完成列表在静止时像进行中列表一样使用日期前的全部可用宽度，只在鼠标悬停、键盘聚焦或无悬停设备上
为可见操作区保留空间。平铺、按项目、短长标题和主题都不得退步。

## 实现

- 仅修改 `desktopSessionMenu.css`，识别官方 2.6.1 的
  `.ha > .ui-tip.okw-sidebar-archive-actions` 结构。
- 有精确指针且行未悬停、未含键盘焦点时，把标题恢复为官方静止渐隐：`--sb-fade: 0px`、
  `--sb-fade-len: 16px`。
- 行悬停或含焦点时保留现有操作宽度；无悬停设备继续常显操作，不缩减触摸目标。
- 统一让增强行的 `.ha` 在静止时不可见且不可点击，避免官方 wrapper 类落在 `.ui-tip` 时误绕过隐藏规则。
- 不修改官方列表 DOM、日期、排序、平铺／按项目偏好、归档接口或会话菜单协议。

## 验证

- 更新桌面会话菜单 fixture，使已完成行与官方 2.6.1 一致：`.ha > .ui-tip > .reopen-btn`，删除按钮位于同一 wrapper，
  三点菜单为 `.ha` 的直接子项。
- 定向 UT 覆盖菜单和归档删除共存、键盘入口、幂等和 CSS 契约。
- 使用准确官方 2.6.1 CSS 和 scoped DOM 属性，在 Chromium 检查 Original 浅色和 Nocturne 深色、平铺和按项目、
  260／296／340 px 侧栏、短标题和长标题。
- 静止时标题渐隐必须为 `0px`；悬停和键盘聚焦时恢复操作区渐隐，操作仍可点击；检查实图无日期重叠或提前空白。
- 发布前运行 lint、typecheck、完整 UT／IT、pack smoke、`git diff --check` 和定向隐私检查。

## 发布

发布目标为 `2.6.1-r7`。从 `develop` 经受保护 PR 合入准确 `main`，从准确 main 创建带注释 tag，
只上传 `open-kimi-web-2.6.1-r7.tgz`，不发布 npm registry，不升级官方 Kimi Code，不自动重启用户服务。
线上资产、安装脚本和旧版 `update --check` 均核验成功后，删除旧 `2.6.1-r6` 的 tgz；保留 r6 tag 和 Release 页面。

## 假设与边界

- 当前兼容基线仍是官方 `2.6.1`／`2.6.0`；未来官方 DOM 改名时增强安全失效，不改写官方状态。
- Chromium 覆盖桌面 hover/focus；本轮不宣称实体触摸设备或其它浏览器已直接验收。
- 本轮只修已完成列表的静止标题空间，不改变操作按钮数量、文案或出现时机。
