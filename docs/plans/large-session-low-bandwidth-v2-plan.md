# 低带宽大会话打开修复 v2

## 本轮范围

- 解决 Open Kimi Web 在约 5 Mbps 链路打开 200–500 MB 会话失败的问题。
- 用户补充授权使用指定现有大会话测试；只读原文件，测试使用隔离副本，不发送模型请求。
- 不提交 Git、不推送、不发布；不升级官方 CLI、不重启生产、不改用户网络或原会话。
- 测试原文、截图、会话标识、路径和凭据不进入版本控制或公开文档。摘要仅保留数量、尺寸、时间与状态。
- 当前 develop 工作树只有既有未跟踪 `.tmp/`，保留不动。

## 已核对的实现事实

- `packages/launcher/src/httpProxy.mjs` 已有流式 gzip 及 120 秒上游 socket 空闲超时，不能把新加 gzip 当修复。
- `packages/launcher/src/responseCompression.mjs` 不缓冲整响应；保持其背压、鉴权、Range、SSE、取消边界。
- `packages/launcher/src/wsProxy.mjs` 双腿 64 MiB 消息上限，浏览器侧未协商压缩，桥接发送缺背压控制。
- 准确官方 npm 2.4.1 主界面每页 10 turns；cold transcript 先完整 fold wire，再分页。
- 每页关联实体仍全量返回，单 turn 没有字节预算；官方请求有 30 秒整体 timeout，解析和渲染还要处理解码后正文。
- 官方初始 WS reset 的 tailTurns=0，但仍带关联实体；live seq catch-up 与 cold 重建不能按旧 2.1.1 fixture 推断。
- running subagent 缺 parent 信息时，官方可自动回溯旧页。不能靠屏蔽它、丢弃消息或截断日志伪造优化。
- OKW 时间戳增强已避免 transcript clone，大正文不另行 JSON.parse，不盲改该模块。

## 2. 按实证实施最小修复

1. 优先在传输层修复已命中的缺口：若 WS 未压缩/发送积压是主要问题，在 `wsProxy.mjs` 做可协商压缩和有界背压，
   保留精确消息/顺序/鉴权/关闭语义及无扩展客户端兼容；不直接取消 64 MiB 安全边界。
2. 若问题是 HTTP 字节量/官方超时，先验证现有 gzip 的实际协商和背压，修复证实的传输错误；不统一无限延时。
   若必要减少官方请求页尺寸，只使用正式 page_size/cursor，保留完整 turn、分页与最新消息，不改业务实体或复制状态管理。
3. 若瓶颈位于官方 cold fold、clone/解析或单 turn 实体大小，明确不能凭 DOM 补丁解决。
   记录最小上游修复点；需要超出外层轻量边界时先更新计划并说明，不偷偷维护第二引擎、缓存数据库或改写官方 bundle。
4. 根据测量选定实际补丁后把结论与范围同步到计划再编辑。新增模块按 officialPresentation 清单约定登记。

### 事件：低带宽打开工具密集大会话缓慢

- 影响：5 Mbps 虚拟局域网用户反馈 200–500 MB 会话打不开；本轮只复现并修复其中可确认的加载／渲染回退。
- 触发条件：增强 UI 无折叠偏好、最近数轮含较多工具输出；主会话初始请求最近 10 轮，关联实体仍全量返回。
- 根因：OKW 将工具活动默认设为展开，增加大量 DOM 与同步工作；同时首屏取 10 轮而非先取最新 1 轮。
  整个 wire 总量不是首屏下载量；现有 gzip 有效，未发现本样本 WS 超大帧或 HTTP 超时。
- 证据：同版真实响应的节点数从官方约 3,614 增至增强约 61,498，最大长任务从 353 ms 增至 2,218 ms。
  正式修后 2.3.1 最近页约 98.6 KB／419 ms，旧请求约 1.14 MB／3.07 秒，均为共享限速单次隔离测量。
- 修复：仅无偏好默认折叠，按精确前端版本将无 cursor main page_size=10 代理为 1；保留原生历史页、正文、实体和 WS。
- 回归验证：标准门禁、准确版本真实响应、真实 2.4.1 浏览器 cold→live／旧页／输入／保持及独立协议重连通过。
  旧测试检查默认值和压缩／透传，没覆盖本轮真实工具密集分布；新增偏好与路径边界测试并补真实浏览器证据。
- 运维动作：需使用本地修改后的 launcher，重启该 launcher 并刷新页面才生效；本轮没有替用户执行生产重启。
  旧浏览器已有展开值不覆盖，需在官方设置手动开启工具活动折叠；无需删除会话或清官方缓存。
- 剩余边界：原虚拟 LAN 的完全打不开仍未复现／复测，巨大单轮和关联实体仍可能慢；未保证任意 500 MB 会话可用。
