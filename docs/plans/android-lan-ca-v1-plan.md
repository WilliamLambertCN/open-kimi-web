# 安卓局域网安装：多地址证书修复 v1

启用本地 CA 必须显式执行；部署与生产重启需要单独确认。

## 用户使用方式

- 支持局域网与虚拟局域网地址，不在文档中记录真实设备地址。
- 手机核对指纹并信任 CA 一次，之后按所在网络打开对应链接。
- 两个 IP 仍是两个浏览器来源；桌面图标不会自动切换地址，不能宣传“一个图标自动跨网”。
- 电脑端按上述授权执行，保留端口、官方安装、会话和凭据；不改网络、系统或手机信任，不提交或发布。
- 停止服务前核对进程树与当前代理宿主，避免误杀自身；只重启已确认归属的服务，不能遗留子进程。
- 手机导入 CA 及最终安装需本人确认；本机监听和证书验证不代替实体手机或两个网络的外部连接验收。

## 已核事实

- 当前 HTML、manifest、图标都正常返回；线上证书为自签的非 CA 服务器证书。
- 用户截图显示证书红叉及“无法安装此应用”，先修证书信任，不把其它 Android 安装条件说成已解决。
- 局域网和虚拟局域网地址都已在 `networks.mjs` 的链接／SAN 枚举中，无需修改网卡或过滤规则。
- `selfsigned` 已锁定 5.5.0；其公开 `generate(..., {ca:{key,cert}})` 支持 CA 签发，无需新依赖、mkcert 或 OpenSSL。
- 此前只验证 Windows localhost 原生安装事件，不能代替 Android 局域网或 WebAPK 安装。

## 实现

1. 独立本地 CA 模块，复用现有证书库。
   - 在 `packages/launcher/src/tls/` 新增 CA 生成／校验、存储及 CLI 模块。
   - CA 为 RSA／SHA-256、`cA:true`、keyCertSign、pathLen 0；叶子为独立密钥、serverAuth、`cA:false`。
   - 验证根自签、有效期与密钥匹配，叶子密钥、签名、用途、SAN 和有效期；叶子到期不超过根。
   - 根保持稳定，只在网卡地址变化或叶子临期时续签叶子；根损坏／缺失／到期明确失败，绝不悄悄换根或降级。

2. 简短且显式的一次性启用入口。
   - `cli.mjs` 提前分发 `open-kimi-web tls setup|status|disable`，help／非法参数无副作用。
   - setup 使用当前 OKW home、当前本机 SAN，生成并验证成功后最后写启用标记；重跑复用根。
   - 与旧 `tls/server.*` 分开存放，保留旧证书；disable 只取消选用，不删除 CA 或修改手机信任。
   - 同目录写入互斥、原子临时文件与有限锁等待；已存在的半套根拒绝自动替换。私钥不打印／不打包。

3. 接入日常启动，不让用户每次输入长参数。
   - `frontend.mjs:resolveTls` 统一 home／env；自定义 cert-file 优先，其次显式启用的本地 CA，再其次旧自签模式。
   - 保留 `kimi web --host`、普通 CLI、默认 loopback HTTP、custom web-dir 与旧用户行为。
   - 不把真实设备地址写入源码或公开文档，不按特定网段硬编码；继续使用既有枚举，包括 Hyper-V。
   - `tlsMessages.mjs` 清楚区分网站证书与 CA 指纹，提示手机只需信任一次及自行重启。

4. 原安装面板补齐下载与手机步骤。
   - `serve.mjs` 增加固定窄路由，仅本地 CA HTTPS 模式 GET／HEAD 返回启动时已校验的 CA DER 公证书及公开指纹状态。
   - 其它模式 404、非法方法 405，不回退 SPA；固定文件名、no-store、nosniff，无目录挂载／签名 API／私钥／路径／token。
   - `mobile/pwaInstall.js`／`pwaInstallView.js` 只在打开面板时获取公开证书状态，显示“下载证书”、CA 指纹及三步指引。
   - 指引：下载 → 与电脑终端核对指纹 → 手机设置搜索“安装证书”并选择 CA → 重开 Chrome 再安装。
   - 保留原主题、布局、语言、焦点和用户手势，不注册 service worker；不以 isSecureContext 断言证书受信任或保证 WebAPK。
   - CA 改变的是手机系统信任，必须由用户明确安装；从未受信连接下载的文件不能仅凭同页面指纹自证可信。

### 事件：安卓局域网 Chrome 显示无法安装

- 影响：已发布 r2 有安装入口，但用户通过未受信任的局域网 HTTPS 访问时，Chrome 只提供快捷方式。
- 根因：默认旧证书是自签的非 CA 网站证书；面板只有泛化提示，未提供稳定根证书和手机信任步骤。
- 证据：匿名静态资源正常，公开 TLS 校验为自签证书错误；原验收仅 localhost，无法覆盖安卓局域网证书信任。
- 修复：增加显式启用的稳定根、独立网站证书、只读公证书下载及核对终端指纹的安装步骤。
- 回归验证：本轮真实 HTTPS/WSS、官方完整 app 实图及标准检查见上；实体安卓结果仍需用户导入后确认。
- 运维动作：使用包含修改的新源码或后续版本，显式 setup 后自行重启实际服务，手机本人核对并导入根证书。
- 剩余边界：当前线上服务未启用；可信证书不保证所有安卓浏览器／安装服务均支持 WebAPK，两地址不会自动切换。
