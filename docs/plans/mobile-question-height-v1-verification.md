# 手机提问卡片高度与长题干 · v1 验收

日期：2026-09-28。实施基线见 [v1 计划](mobile-question-height-v1-plan.md)。

## 环境与边界

使用官方 Kimi Code `2.1.1` 完整 Web 应用、系统 Chrome 的独立浏览器上下文和回环 launcher，
API 与 WebSocket 使用虚构 fixture。题干直接填入真实 `question` 字段，不手工拼装卡片 DOM。
没有替用户回答真实会话，也没有操作用户正在使用的 Chrome 或服务。

截图与原始指标归档在本地忽略目录 `.cache/question-long-title-qa/`，不包含于 Git 或发布包。
主代理实际查看 Original 浅深色、五个主题、长题、低档位和短题前后对照截图。
这些结果证明隔离浏览器中的组件行为；实体手机、真实软键盘和真实会话仍需用户复验。

## 问题与修复证据

306 字虚构题干、4 个选项加其他，在 390×844 视口复现 `r3`：卡片 422px、头部 369px，
`.qbody` 仅 16px，底部操作区超出卡片。此前回归把长内容放进 `.qbody`，没有覆盖真实题干头部。

| 场景 | 修复后实际卡片高度 | 正文可视高度 | 交互结果 |
| --- | ---: | ---: | --- |
| 390×844，默认 | 422px | 285px | 首末选项可点，提交单选 ID 正确 |
| 320×568，默认 | 284px | 147px | 首末选项可点，提交正确 |
| 390×440，默认 | 220px | 83px | 首末选项可点，提交正确 |
| 390×440，35% | 187px | 50px | 按安全下限抬高，首末选项仍可点 |
| 390×300，默认或 35% | 187px | 50px | 高度受限时保留可操作区域 |
| 320×568，85% | 462px | 325px | 受顶部安全距离限制，未越屏 |

选项检查使用与滚动区的可见交集、`elementFromPoint` 命中及真实指针点击，
随后验证官方组件发出的答案请求。单选、多选和其他文本分别验证，未使用强制点击绕过遮挡。

## 外观与交互

- Original 浅色/深色、夜幕、极光、暮色、余烬、矿物青绿的长题显示及选项提交通过。
- 标题展示副本与原始题干计算字体一致：14px、字重 500、行高 21px；文本完整。
- 短题与 `r3` 在夜幕、Original 浅色下对照：自然高度仅增加 24px 把手，
  正文和底部按钮位置、按钮宽度、字体及面板颜色保持一致。
- 短题→长题→短题、上一题/下一题、收起/展开通过；单题双按钮与多题三按钮保持横排。
- 鼠标拖动 50→70→35，原生触摸拖动 35→85，实时预览与最终档位吻合。
- 原生触摸取消恢复 85 档，不保存取消位置；刷新后恢复同一档位。
- 方向键、Home、End 覆盖四档；844px 高度缩至 440px 后保留偏好且选项可点。
- 1280×800 桌面没有注入把手、固定高度或题干副本，手机偏好仍保留。
