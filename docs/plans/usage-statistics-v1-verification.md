# 用量统计 v1 验收记录

日期：2026-09-28。基线为 [实施计划](usage-statistics-v1-plan.md) 和官方 Kimi Code 2.1.1。
以下记录对应功能验收时的工作树；后续提交与发布状态见 README 和 Git 提交记录。

## 数据与功能

- 六个预设为 `1d / 3d / 1w / 1m / 2m / 3m`，对应最近 1、3、7、30、60、90 天。
- 隔离的官方 2.1.1 服务创建虚构工作区和会话，按官方 wire shape 写入 92 天演示记录。
- 六个范围的普通输入、缓存读取、缓存写入、输出和请求数，均与独立求和结果一致。
- 模型、工作区及组合筛选、自定义起止时间、半开时间区间、空数据与错误恢复通过。
- 主 agent、Side Chat、两层 fork、重复读取、追加、截断、删除、坏行和来源缺失有定向覆盖。
- 命中率使用缓存读取量除以总输入量；趋势保留无调用时段，不压缩日期间隔。
- 用量缓存只保留统计事实；响应不包含会话正文、标题、凭证或绝对路径。
- 未授权和错误 Bearer 均被拒绝；外部 target 明确返回不可用，自定义 Web 构建不开放增强接口。

## 模型身份修正与多模型验收

- 官方 `usage.record.model` 是别名，现改用同一 agent 的 `llm.request.model` 确认当次 API 模型 ID。
  官方适配器把 `model.name` 放入协议请求的 `model`；请求记录中的 `provider` 是协议，不能推断渠道。
- 相同 ID 的多个别名合并；同一别名改绑两个 ID 时分开；别名不参与价格映射键或筛选键。
- 缺少请求、并发冲突、失败重试残留、损坏/超长行和 fork 边界均有针对性测试。
  不确定记录保留 token 并归为“模型 ID 未确认”，不自动估价，也不能进入价格编辑。
- 多候选请求消费后不会保留旧 ID；loop 的歧义持续至可信 `step.end`，session/compaction 的歧义
  因缺少等价边界保守持续至 fork 或文件末尾。现有记录不足时不能承诺恢复每次调用的身份。
- 价格设置新增身份版本；旧别名映射经字段投影后只在本机隔离保存。
  自动刷新、手动保存和重启不会丢弃这些映射，也不会把它们应用到真实模型 ID。
- 隔离官方页面使用 48 个模型 ID、1 组未确认记录和 290 次请求；独立求和为 9,186,260 token。
  页面及接口与期望一致；覆盖同 ID 两别名、同别名两个 ID，以及超长模型 ID。
- 桌面 1440px 和手机 390px 视口，分布与明细均可用滚轮和键盘到达最后一项。
  手机触摸事件实际移动两个内层列表；48 个模型均保留，长 ID 不撑宽 360px 手机视口。
- 多项内容显示数量与滚动提示，筛选至单模型后提示隐藏。
  尾部模型可搜索、筛选和保存单价，网络请求传真实 ID，不传别名或筛选键前缀。
- 实际联网刷新得到 7,909 个价格目录条目；最后一项可以精确搜索、选择和保存。
  内置小目录可直接选择，大目录明确显示搜索门槛和 200 项展示上限。

## 定价

- 内置 13 个公开模型快照的四类基础单价，与本次实际获取的 models.dev 数据逐项一致。
- 实际页面联网刷新成功，返回 7,909 个目录条目，来源为 models.dev 和 OpenRouter。
- 通过页面操作验证目录搜索、映射保存、纯手动单价、显式零价、移除映射及保留手动配置。
- 集成测试覆盖刷新失败保留目录与映射、重启读取配置、未授权写入和无效输入。
- 并发刷新合并、串行持久化、失败退避、缓存结构与字段投影有定向测试。
- 长上下文按单次请求选档；models.dev 的未知阶梯价和 OpenRouter 的部分覆盖使用各自语义。
- 更新后的多模型演示周数据为 9,186,260 token，命中率约 70.6%；手动价格下已知小计约 USD 11.6298。
  另有 10 token 因模型 ID 未确认而未定价，页面明确展示，不将它们计为免费。
