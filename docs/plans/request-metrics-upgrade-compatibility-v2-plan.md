# 请求指标的官方升级兼容修复 v2

## 目标与授权

用户指出官方升级后逐调用统计可能消失，并追加要求“修好发布”“通通放行版本”。
取消指标补丁的所有版本号门禁，只以实际bundle的完整结构判断能否适配，不能硬改坏页面。
本轮发布 `2.5.2-r4`，包括提交、推送、PR合入main和新GitHub Release；不升级用户CLI、不重启生产、不改旧tag或资产。

## 已确认的事实

- 当前命令报告2.5.2；本机48627首页已引用step-metrics-v2路径，实际JS约4.2MB，含 `__okwTimingSlots`。
  未鉴权meta返回401，没有读取凭据或真实会话；不能据此假称生产后端已是2.5.3。
- 官方npm已发布2.5.3，隔离安装未执行安装脚本。原版2.5.3主bundle通过既有全部语义匹配；
  只因三个入口硬编码2.5.2而跳过。6.5KB是当前首页HTML的大小，不是主JS。
- 原测试将2.5.3明确视为不支持，只有2.5.2 fixture，未覆盖官方补丁升级。

## 改动

1. 按最新要求取消指标补丁的所有版本限制，旧版、新版、预发布及未来主版本均可尝试。
   只由实际入口bundle的完整语义校验决定是否启用，不用白名单、范围或某个标记代替。
2. 启动时核对实际index模块入口及其原始JS。验证成功才改写整个模块图；失败原子保留官方资源，
   不出现“首页走增强路径，但JS未打补丁”的假成功。不修改官方缓存原文件。
3. 用固定启动日志及首页meta记录active／incompatible-bundle／unavailable-bundle。
   不打印本地路径、凭据或源码；不能用带namespace的URL单独当作成功证据。
4. 无论启用与否，指标私有资源路径均不返回SPA首页；错误路径返回404，继续拒绝map、隐藏文件和目录逃逸。
5. 已验证的入口表示保留在实例内，不为每次静态请求重复执行大bundle的全部正则；磁盘入口发生变化时拒绝，
   不默默下发不带补丁的旧表示。主聊天、历史身份、平均TPS和缓存口径不变。

## 验证

- UT覆盖结构缺失／重复／变化、入口解析、安全路径和状态；IT用旧版、补丁版、次版本、主版本、预发布和缺版本证明不查版本。
- 实际HTTP覆盖2.5.3与兼容未来版本fixture、失败原子回退、状态meta、日志、HEAD／gzip、依赖图及404边界。
- 对准确官方npm2.5.2／2.5.3资源检查真实首页引用、JS类型、字节数和补丁标记，不用fixture冒称真实包。
- 在隔离2.5.3原后端、本地虚构provider及完整app中实际发送，核对平均TPS／缓存、历史及双端三主题实图。
  不重复2.5.2已通过且未变的浏览器矩阵；不发付费调用、不读真实历史、不启debug。
- 跑受影响UT／IT、标准lint／typecheck和实际包检查，保留首败，清理自有进程、profile与临时home。
- 更新launcher／插件及当前文档至r4；官方完整兼容基线、安装pin及fallback不自动扩大。
  定向隐私检查后正常提交develop，经required CI合入main，再从准确main标准打包、新annotated tag与latest Release。
  公共下载核对原字节／digest、同SHA安装入口及真实旧r3更新发现；旧r3保持不变，记录发布证据后同步main回develop。

## 边界

本轮“全版本放行”指当前讨论的请求指标补丁，不把任务、最近页、全局子模型等其它协议的门禁无验证删除。
未来结构改变时明确降级，不保证所有未来版本都有同一结构。首次生产停止失败仍未确认，不借本轮验收改写历史。

### 事件：官方升级后请求指标可能悄悄停用

- 影响：升级前端后，TTFT、平均TPS和缓存可能消失，单看页面能打开无法判断适配状态。
- 触发条件：旧实现仅认2.5.2，即使2.5.3仍满足全部语义契约也拒绝；资源路径本身不是补丁成功证据。
- 根因：三处精确版本比较与“2.5.3应不支持”的测试绑定，未用实际入口校验驱动整体激活。
- 证据：隔离npm2.5.3的全部结构匹配；生产静态只读检查中2.5.2已带补丁，6.5KB实际是首页HTML，
  不能把该响应误判为主bundle，也不能据此说当前生产已升级2.5.3。
- 修复：取消所有指标版本比较，启动时验证完整结构，成功统一改写资源图；失败保持原图并记录原因。
- 回归验证：上述108 UT／29 IT、准确双版本资源和2.5.3真实后端／浏览器30项覆盖实际触发条件。
- 运维动作：正式更新后用户需停止旧服务、照常启动并刷新；不用迁移会话或清官方缓存。
- 剩余边界：未来结构改变仍可能不适配，不冒险改坏页面；任务、最近页等版本边界不扩大。
  其它平台、实体手机和首次生产停止异常没有借本轮宣称已解决。
