# 手机提问卡片高度与长题干 · v1

状态：用户已确认拖动调高并自动保存；实施基线为官方 Kimi Code `2.1.1`，随 `v2.1.1-r4` 发布。

本轮实际结果见 [v1 验收记录](mobile-question-height-v1-verification.md)。

## 目标与现有问题

真实 `question` 渲染在 `.qh .qtitle`，官方头部不参与收缩。约 300 字题干可占满半屏卡片，
将 `.qpane` 内的选项和底部按钮挤出可用区域。此前对 `.qbody` 正文滚动的修正未覆盖此路径。

保持已确认的卡片外观、选项反馈、横排按钮和主题配色，让题干可读、选项可选、操作按钮可达，
同时允许用户上下拖动卡片上沿调整高度，松手保存档位。

## 交互与视觉

- 手机展开卡片的上沿增加独立拖动把手，只有把手接管拖动；题干和选项仍使用正常触摸滚动。
- 提供 `35%`、`50%`、`70%`、`85%` 四档，默认 `50%`。拖动实时预览，松手吸附最近档位。
- 未手动设置时，短题保持自然高度，上限为半屏；手动设置后使用所选高度并限制在可用视口内。
- 只在有效结束拖动或键盘操作后保存白名单数字；取消拖动恢复原高度，不持久化中间状态。
- 档位保存在当前浏览器、当前站点，刷新、切题和再次打开沿用。不保存题目、答案、会话或路径。
- 把手具备 slider 语义、当前档位说明和上下方向键、Home、End 支持。
- 视口变化或软键盘压缩可用空间时限制实际高度，保留顶部安全距离。桌面和收起状态清除高度覆盖。
- 小高度下根据把手、头部、正文内边距和底部操作区计算最低可操作高度，必要时抬高实际卡片，
  为选项保留至少 44px 点击区域；保存的偏好档位不变。

## 长题干保护

- 根据题干实际高度、底部操作区及选项可用高度判断，不使用固定字符数或上游构建 hash。
- 超高时保留官方 Vue 管理的原始题干节点，以可测量但不可见的方式撤销其头部占位。
  只通过 `textContent` 将完整题干展示副本放入 `.qbody` 首部，与选项共同滚动。
- 短题、桌面及收起状态撤销展示副本；切题、展开和视口变化时更新，不残留旧题干。
- 保持官方字号、字重和行高；不移动官方节点、不截断题干、不改变题目与答案状态或提交协议。
- 新题可归顶，普通 resize 不重置阅读位置；拖动时保留已经进入正文的题干。
  缩小时如出现挤压则启用保护，放大时等到松手再决定是否恢复题干头部位置。
- 增强必须幂等，DOM/尺寸变化合并到下一帧，只处理相关卡片。卡片移除时释放观察与事件引用。
  不扫描主会话历史或 Side Chat 消息。

## 验收

- 使用官方 `2.1.1` 完整应用和虚构 API，题干写入真实 `question` 字段。
- 覆盖短题、306 字题干、4 项加其他的单选、5 项多选、短长短切题、收起展开。
- 检查 390×844、320×568、390×440 等视口，Original 浅深色与 5 个主题以及桌面边界。
- 实际滚动并点击首项、末项和其他；验证可见交集、命中点、操作区边界及提交的答案内容。
- 验证鼠标和触摸拖动、四档吸附、刷新与切题持久化、取消、键盘、非法存储及存储异常。
- 35% 低档仍能阅读点选，85% 高档不越屏；视口收缩后正常限制高度。
- 使用真实 MutationObserver 验证收敛，回调内部设置断开保护；无关流式内容不触发布局扫描。
- 主代理查看代表实图，完整发布 gate 通过后才发布。实体手机实际操作仍由用户复验。
