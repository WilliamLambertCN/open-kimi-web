# contracts/upstream

`openapi.json` and `asyncapi.json` are historical reference snapshots from
upstream kap-server CLI 0.41.0. `metadata.json` retains the source commit,
capture date and original artifact checksums. The standalone client and its
contract capture/test workflow have been retired. These snapshots are not
an active compatibility check; see [`UPSTREAM.md`](../../UPSTREAM.md).
